## Outcome

The [plan](F2.plan.md) and [service README](../../../packages/server/src/remote-attempts/README.md)
define the bounded slice. Optional F1 configuration enables signed owned-node inference
offers with an explicit executor and home execution fence. Home intent is recorded under
R1's existing attempt transaction. Target queued/reserved metadata is protected by its own
R1 home generation, including after asynchronous governor admission. Admission uses the
actual process-local Resource Governor; exact retries share one ticket, changed payloads
conflict, and newer fences invalidate old reservations after commit.

Both protocol minor **2** and the distinct `attempt-reservations-v1` capability are required.
U1-only peers are not inferred to support attempts. The additional handshake field is omitted
for older strict readers, including an older major with a numerically high minor. Same-owner
owner-device permission, exact target id and a host-pinned run/home/epoch are mandatory.

Every receipt has **`dispatchAuthorized: false`**. This feature contains no execute method
and starts no model, workspace or external effect. Resource reservation is not run execution
authority, model/window fit or measured host capacity. Current owner scope remains local
Mac/Colima only: no SSH, remote host, provider, installed model or owner data was used.
