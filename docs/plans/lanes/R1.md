**Goal:** a lead can delegate, sleep at zero tokens and wake exactly once.

**Scope:**

- Additive SQLite migrations: `run_attempts`, `leases`, `promises`, `timers`, `outbox`.
  Append-only; never rewrite an applied migration.
- Run states including `waiting_children` and `wrapping_up`, with the A2A mapping.
- The restart reconciliation table.
- Signals versus promises, and wake versus delivery.
- Retained run-scoped resources.
- Cancel along the chain, exactly once.
- A cost ledger per run.

Build these as kernel plugins and kernel services, and record run events in the K2 session
log.

**Exit gate** (each item needs an assertion that fails when violated):

- A property test over every crash point of hibernation **and** wake gives one resolution and
  one acknowledged wake.
- A deadline wakes the lead when the child never finishes.
- A stale completion wakes nobody.
- An escalation followed by a completion produces two wakes and one resolution.
- The lead's worktree survives an 8-hour hibernation (simulated clock).
- Canceling a hibernating lead cancels its children exactly once.
