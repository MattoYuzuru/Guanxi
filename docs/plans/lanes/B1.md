**Goal:** measure before adding scaffolding.

**Scope (ROADMAP §B1, ADR-0025):**

- **Harbor.** Run it as a managed external process: a pinned Python environment, never
  bundled.
- **Arms.**
  - mini-swe-agent is the permanent control arm.
  - Guanxi joins through ACP or `exec --json`.
- **Task sets.**
  - 50 fresh SWE-rebench tasks.
  - 30 SWE-bench Verified tasks as regression.
- **Statistics module.**
  - Paired bootstrap, McNemar and pass^k.
  - Non-inferiority at −5 points, superiority, and Holm correction.
- **Report and caps.**
  - An HTML report, built with `@guanxi/ui` tokens if it renders in the app. A standalone
    file is fine.
  - A noise-floor procedure: one arm × 5 seeds.
  - Budget caps that refuse a run before it would exceed its cap.
  - Infra errors reported separately from task failures.

**The benchmark host is provisioned.** It is live and verified by the integrator on
2026-10-21, using `scripts/infra/provision-bench-host.sh`.

- Reach it as `ssh fedora` followed by `sudo -n -u guanxi-bench env HOME=/home/guanxi-bench XDG_RUNTIME_DIR=/run/user/1001 DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/1001/bus podman …`.
  Run it from a neutral working directory such as `/tmp`.
- Rootless Podman 5.8 with the systemd cgroup manager.
- Containers land in `user-1001.slice`: 8 of 12 CPU threads, `MemoryMax=14G`, low CPU and IO
  weight. They have no GPU devices.
- Never touch the owner's workstation services (`workstation-*`), the llama server on 8080
  holding the GPU, the VPN or the keykomi relay.
- Never run benchmark containers as `yuzuru` or as root.
- Make the runner target this host through a configuration value, not a hardcoded alias, and
  make the Mac's fixture smoke path work with no host.

**Budget and live runs:**

- Tests use fixtures only: recorded results, fake arms and a toy task image built locally.
  They never use live models or the network.
- One end-to-end smoke on the bench host is allowed: 1–2 tasks, a free local or
  fixture model, $0 spend. Record its receipt.
- Any paid run, such as a DeepSeek Flash noise floor, needs the integrator's explicit go-ahead
  and must stay inside the D-150 cap. Do not start one yourself.
- No secrets in configs, logs or reports. API keys come through K3 connections as `secret://`
  references.

**Exit gate.** Each item needs an assertion that fails when the property is violated; prove it
by removing the guard.

- The statistics module matches Inspect AI reducers on a fixture. Copy or port only under an
  allowed licence, and record it in THIRD_PARTY_NOTICES.
- A planted 10-point regression is detected.
- Infra errors are reported separately from failures.
- Spend stays within the cap: a run that would exceed it is refused before it starts.
