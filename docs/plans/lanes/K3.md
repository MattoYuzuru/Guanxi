**Goal:** one connection registry for subscriptions, API keys, local runtimes and services.

**Scope:** ROADMAP §K3:

- connection kinds and capability facts with provenance (source, observedAt, confidence);
- vault with a keychain-wrapped key; `secret://` references and just-in-time injection;
- pi-ai integration with the Anthropic OAuth path disabled;
- balance probes with recorded fixtures; a cost ledger per connection;
- local runtime adapters on this node, starting from the legacy Ollama adapter that K1 moved
  into a kernel plugin;
- search and STT connection kinds;
- `unattended` connections per D-145, off by default.

**The egress scrubber is owned by K2.**

- Use its documented `egress.scrubber` kernel service at model-request construction and at
  artifact write, and register vault secrets with it.
- Until K2 merges, code against that interface with a minimal local stub, and delete the stub
  after merging main.

**Owned paths:**

- `packages/server/src/connections/**`, `packages/server/src/vault/**` and
  `packages/server/src/probes/**` (new);
- `packages/contract/src/connections/**` (new files; append re-exports);
- the connection plugins;
- the Connections settings page under `packages/web/src/features/connections/**`. UI work
  follows `.agents/skills/guanxi-ui/SKILL.md` by hand, because DS1 is not merged yet.

**Secrets:** never put a real secret in code, tests, fixtures or logs. Tests use generated
fake keys and a throwaway keychain or file vault in a temp directory, never the owner's
keychain or `~/.guanxi`. No live provider calls in tests: probes use recorded fixtures.

**Exit gate** (each item needs an assertion that fails when violated):

- a secret printed by a tool never reaches the next model request (end-to-end trace test);
- balances without `observedAt` render `unknown`;
- each probe has a recorded-fixture contract test;
- pi-ai's Anthropic OAuth path cannot be enabled;
- an `unattended` connection is off by default.
