Goal: the same Guanxi on several machines, sharing data without a hub.

Scope (ROADMAP §F1):

- node trust classes (`owner_device`, `shared_device`, `cloud_ephemeral`) and enrollment by
  device authorization;
- private-network guidance (documentation, not changes to any real network);
- telemetry with provenance;
- the shared-config op-log: HLC with a drift bound, remove-wins grants, identity writes from
  admin nodes only;
- scoped replication of session and run logs, single writer per stream;
- a versioned federation contract in `packages/contract/federation`;
- command routing bound to state versions.

**Testing:** use in-process multi-node simulation with simulated network partitions, delays,
reordering and clock skew. A deterministic simulation harness is the main evidence. Do not
touch real networks, VPNs, SSH routes or other machines. The integrator validates on the
owner's Linux nodes separately.

Exit gate (each item needs an assertion that fails when violated):

- replicas converge to an identical state hash after random op interleavings;
- a revoke concurrent with a grant wins;
- a delayed stop never cancels work started after it;
- a `cloud_ephemeral` or non-owner node receives 0 vault records, 0 session replicas and 0
  reasoning events;
- unauthenticated nodes are refused;
- peers on an older major contract are read-only.
