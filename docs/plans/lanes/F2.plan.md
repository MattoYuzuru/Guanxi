# F2-a — owned-node offer reservations

**Status:** authorized bounded implementation · **Date:** 2026-10-22.
**Branch:** `codex/ms1-f2` · **Base:** reviewed U1 `e5f8e0a`, main `c09e2be`,
merged as `342ad92`. Node 26, local Mac only, ports 5201/4401 and own `.lane-data`.

Add a signed owned-node inference offer with explicit home, executor and execution fence.
The home records intent in the existing R1 attempt transaction. The target requires a pinned
run/home binding, same-account owner-device grant and actual local governor admission before
recording a bounded reservation. Protocol minor 2 and a distinct advertised capability prevent
U1-only minor-1 peers from being mistaken for remote-attempt support. Default federation
starts no offer service. Receipt `dispatchAuthorized: false` is normative: no inference,
workspace, model install or external effect runs from this receipt.

Independent additive migration 36 stores immutable home intent, target offer state and
per-run fence watermarks. Existing migrations and U1 component v1/v2 remain unchanged.
Duplicate offers share one admission; changed payloads conflict; TTL, cancellation, fencing,
restart and shutdown release/invalidate the reservation. Target metadata commits under the
node's R1 home generation, including across asynchronous governor waits. No public user API,
UI, paid provider, model call, host probe or owner data is added. Rollback disables the optional
service and retains evidence; no destructive down migration.

Assert signed channel/version/capability and ownership failures, explicit executor identity,
governor-before-receipt, concurrent idempotency, target TTL/release, restart invalidation,
home stale-fence zero writes, newer-fence invalidation, deposed target-home refusal and
schema rollback/persistence. Run focused fixtures and contract/server tsc locally; root owns
heavy full gates and merges. Review is a separate GPT action, with fixes in separate commits.

F2-b still owns lease validation/renewal at the holder, actual dispatch and event/completion
ingest, direct cancellation, side-effect classes, handover/restore epoch and power assertions.
No F2 stage exit or six-hour MS1 claim follows from a resource reservation.
