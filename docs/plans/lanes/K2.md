# Lane K2 — Session log and inspector

**Status:** ready · **Updated:** 2026-10-20 · **Runs in:** Claude Opus session ·
**Ports:** `GUANXI_WEB_PORT=5186`, `GUANXI_API_PORT=4386`

Follow the lane rules in [README](README.md). The task is ROADMAP §K2 (goal, scope, reuse,
exit gate) and [ADR-0023](../../decisions/0023-session-event-log-and-tracing.md). Build it as
plugins on `@guanxi/kernel` ([ADR-0037](../../decisions/0037-own-plugin-kernel.md)); K1's
residuals in [evidence/K1](../evidence/K1.md) name the pinned legacy rows K2 may unpin.

## Owned paths

- The session log and event store, `packages/server/src/session-log/**` (new), and the port of
  the legacy durable job/event store behind a single-writer `SessionHandle` contract.
- Event schemas in `packages/contract/src/events/**` (new files; append re-exports to
  `index.ts`).
- **The egress scrubber core,** `packages/server/src/egress/**` (new):
  - exact-match redaction of registered secret values;
  - exposed as a kernel service `egress.scrubber` with `register(ref, value)`,
    `unregister(ref)` and `scrub(value)`.

  K3 consumes it for model requests and artifacts and registers vault secrets. Document the
  interface first and keep it stable.
- **The interim inspector:**
  - timeline, spans, FTS5 search and token meter under `packages/web/src/features/inspector/**`;
  - its server routes;
  - the agent query tool.

  UI work loads the `guanxi-ui` skill. DS1 is not merged yet, so follow the design rules by
  hand and say so in the hand-off.

## Must hold

- Crash at every append point never yields a torn or duplicated event (fault injection).
- Replay reproduces UI state (count assertions).
- A planted secret never appears in events or exports.
- An agent on a remote provider receives 0 reasoning events (D-113).
- Reasoning is never written to plain logs.
- Migrations are append-only.
