# K4 — Native agent handoff

**Status:** BLOCKED; partial implementation, not ready to merge · **Updated:** 2026-10-21

**Branch:** `lane/k4-native-agent` · **Base/main:** `750e167` · **Final code:** `537b95a`

## Outcome and blocker

The native pi-agent-core loop, K3 dispatch, K2 event projection, sandboxed file/search/fetch
tools, attachments, light plan/queue/notes, project roots, interim session UI and JSON CLI are
implemented. This does **not** complete K4: reliable ownership of detached descendants is
missing. Independent review demonstrated a detached process writing to a permitted root after
the command runner returned and its session ownership could be released. Killing a process
group cannot guarantee descendant termination.

Arbitrary shell execution therefore fails closed in **both** access modes. Only fixed
absolute `pwd`, `ls`, `cat`, `head`, `tail` and `wc` binaries with plain arguments are exposed
by `shell`; trusted file/search/fetch implementations use fixed commands. The UI and tool
description disclose the limitation. Do not enable arbitrary programs or converters until a
kernel/native supervisor owns their whole lifetime. This restriction mitigates exposure but
does not resolve the missing K4 capability or its lifetime guarantee.

Per [lane rule 11](README.md#rules-for-every-lane), this handoff leaves the lane blocked on the
same slice. The roadmap and exit gate have not been reduced to fit this result.

## Implementation and compatibility

Implementation details: [native-agent README](../../../packages/server/src/native-agent/README.md).

- The frozen `agent.native` facade depends on `connections.registry`, `session.log` and
  `egress.scrubber`. API models use K3 `complete`; local Ollama uses K3 `localChat` with
  explicit context and the governor. Subscription-agent adapters remain K5 work.
- Policies snapshot roots, mode, network allowlist, protected paths and selected attachments.
  Existing protected links retain lexical and canonical denies; dangling protected links
  refuse creation. Staging paths derive from canonical node data paths.
- Native root overrides use a private `native-projects.sqlite` sidecar, schema v1. Missing
  overrides fall back to legacy Project bindings; an explicit empty override means scratch
  only. Legacy Chat bindings and shared node migrations remain unchanged. Removing the
  sidecar restores legacy bindings for new sessions; recorded session policies remain intact.
- K2 stores prompt, assistant, tool, policy, progress and reasoning events. Reasoning uses
  K2's reasoning class, is excluded from model context and CLI results, and is never sent to
  console logs. Model contexts, tool arguments/results and event writes use the scrubber.
- Explicit continuation reconstructs history. There is no automatic inference after restart.
  Durable run scheduling/recovery belongs to R1.
- `/agent` and `/agent/:id` reuse legacy primitives with DS1-a tokens; no DS1-b dependency,
  generated-token edits or component approval was introduced. Progress includes provenance,
  plan verification requests, queue, response, stop and continuation.
- This is an unmerged new K4 API. Sessions created by earlier development commits of this
  lane must be recreated; no deployed K4 policy migration is claimed.

Exact npm dependencies: pi-agent-core 1.3.0 (MIT), sandbox-runtime 0.0.81 (Apache-2.0), TypeBox
1.3.27 (MIT). Tagged upstream licenses are linked in the implementation README. No upstream
code, prompts or assets were copied, so no new THIRD_PARTY_NOTICES entry is required. The
license gate checks 441 npm packages with 0 disallowed; it is not a native-binary audit.

## Remaining scope and recovery

Resume K4 on this branch. Do not mark its roadmap gate complete or open dependent work from
this handoff.

1. Implement a supported OS/native execution owner that retains every descendant across
   detach/double-fork and terminates all owned processes on completion, stop, timeout and
   unload. Retain root ownership until cleanup is confirmed. Keep the public execution
   restriction until this guarantee has direct assertions.
2. Add temporary-only regressions for the demonstrated late-write case and for cancellation,
   timeout and unload, proving no post-release writes or second overlapping writer.
3. Close the independent-review evidence gaps before claiming the corresponding properties:
   overlapping-root exclusion; running-session restart with zero automatic inference;
   dependency/Node write denial; positive HTTPS, Unix-socket/local-bind restrictions;
   attachment/image dispatch; UI retry/continuation, keyboard stop/removal and long-content
   mobile behaviour. Existing browser evidence covers keyboard start, exact replay counts,
   reduced motion and a 390px viewport, not all themes or assistive technologies.
4. Finish native-session/artifact retention integration and the all-tool artifact/output
   policy. State/query outputs and large inputs are still inline; only command stdout/stderr
   have an explicit 64 KiB truncation flag. Binary conversion is currently unavailable.
5. Repeat required gates and independent review, then let the integrator arrange the Claude
   cross-family review and fold evidence into PHASE_STATUS/NEXT_AGENT_PROMPT after completion.

Linux is unvalidated and depends on upstream bubblewrap/seccomp provisioning. Windows refuses
execution. Concurrent external host processes altering project trees remain outside the
process-local native writer ownership; no machine-wide lease or production security claim is
made by this lane.
