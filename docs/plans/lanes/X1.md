**Goal:** agents find code fast and cheaply in any project root, across worktrees.

**Scope (ADR-0030):**

- IX0 grep/ripgrep: always available as a tool. Do not bundle a ripgrep binary you cannot
  license-check; fall back to a Node implementation.
- IX1 tree-sitter repository map, built automatically. Use tree-sitter or web-tree-sitter
  grammars under an allowed licence (ADR-0016), pinned exactly. Cover TypeScript/JavaScript,
  Python, Go, Rust, Java, C/C++ and Markdown headings as a start; a missing grammar degrades
  to file-level entries and never fails.
- IX2 SQLite FTS5 trigram index (`node:sqlite`), built automatically above a repository size
  threshold. The threshold is a documented setting, not a hidden cap.
- Everything is keyed by content (git blob SHA or chunk hash), so worktrees of one repository
  share entries and re-indexing is incremental.
- Index builds are idle-priority runs with preemptible leases and are cancellable. Respect
  D-189 headroom on the machine in use, and never block an interactive request.
- LSP is used directly where a server is installed. Serena v2 is GPL-3.0: separate process
  only, never bundled.
- Native-agent tools: `repo.map` (budgeted output with a token bound stated and asserted) and
  `search` (FTS with grep fallback), with provenance (index age, commit, coverage) in every
  result.
- Read-only project roots stay read-only. The index lives in Guanxi's data directory, never
  inside the user's checkout.

**Exit gate.** Each item needs an assertion that fails when the property is violated. Prove
it by removing the guard.

- The index stays fresh after branch switches across worktrees. Use a real temporary git
  repository with two worktrees: switch branches, edit, delete and rename files, then assert
  that results match the checked-out tree exactly, with no stale hits and no missing hits.
- Shared content is stored once across worktrees (count assertion).
- An interrupted build resumes or rebuilds without a corrupted index (crash-point test).
- Secrets and ignored files are not indexed: `.gitignore`, `.env*` and K2 scrubber-registered
  values are excluded (assertion on stored rows).
- Embeddings are off: no IX3 code path runs unless its flag is set (test).
