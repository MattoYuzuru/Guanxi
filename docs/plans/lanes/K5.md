**Goal:** use the owner's subscriptions through official agents, and bind roles to
connections.

**Scope (ROADMAP §K5):**

- ACP client adapters: Claude Code with the user's own binary, Copilot, Gemini CLI, OpenCode
  and Goose.
- A Codex app-server adapter and a "Sign in with ChatGPT" provider.
- A capability declaration per adapter.
- Role resolution, session first and then project.
- Isolated vendor config directories.
- Quota facts reported by the agents: Claude Code `rate_limits` and Codex
  `account/rateLimits`.
- Subscription agents on any node, each signed in on that node with the unmodified CLI.
- Owner-bound subscription connections (D-190).
- Account-wide limit aggregation, and learned concurrency per account.

**Hard constraints:**

- **Licensing (ADR-0016).** Claude Code and the Claude Agent SDK are proprietary: process-only,
  never bundled, never copied, and never a dependency in any `package.json`.
  - Drive the user's installed `claude` binary over a documented protocol.
  - If an ACP bridge for Claude Code depends on the Claude Agent SDK, it may only be a separate
    program the user installs. Guanxi then talks to it as a process, and the hand-off says so.
  - The ACP SDK, the Codex app-server protocol and the Copilot SDK may be used only if their
    licences are verified as allowed. Pin them exactly and keep `npm run check:licenses` green.
- **D-190.**
  - Guanxi never reads, copies or moves vendor tokens or credential files, and never imitates a
    vendor client.
  - Each machine signs in with its own unmodified CLI.
  - A subscription connection is bound to its owner: a prompt from another account that would
    reach it is refused.
  - Only API-key or local connections may pay for an editor's prompts, and only when the owner
    allows it.
- **Data rules.**
  - Quota and billing facts carry their source, observation time and confidence; an unknown
    stays unknown.
  - Every model call goes through K3 connections and the `egress.scrubber`, and events go to
    the K2 session log.
  - No reasoning in plain logs, and no secrets anywhere.
- **Tests never run a real vendor CLI or use the network.**
  - Use recorded sessions per adapter version, replayed by fixture binaries in temp
    directories.
  - Never touch the owner's real `~/.claude`, `~/.codex`, `~/.config` or keychain.

**Exit gate.** Each item needs an assertion that fails when the property is violated; prove
it by removing the guard.

- Recorded-session tests pass for each adapter version.
- Golden tests cover role precedence.
- The Claude Code `--bare` versus subscription state is detected and reported.
- A second account's prompt that would reach a subscription connection is refused.
- No Guanxi code reads a vendor token file. Prove it with a static check that fails on a
  seeded read, plus a runtime test.
