**Goal:** a usable light agent on any connection.

**Scope:**

- The agent loop on `pi-agent-core`. Pin the version exactly and check its licence per
  ADR-0016.
- Tools: files, shell, search, fetch, attachments, plan/queue and `note.add`.
- An orientation block of at most 300 tokens.
- Read-only and Full access enforced by Anthropic `sandbox-runtime`, with the egress proxy and
  the deny-write profile. Pin it, check its licence and record it in THIRD_PARTY_NOTICES if
  code is copied.
- Projects with zero or more roots.
- An interim new-session screen.
- `guanxi agent exec --json` (REQ-M1).
- A session-level progress view (REQ-C9).

All model calls go through K3 connections and the `egress.scrubber`. All events go to the K2
session log. Never put reasoning in plain logs, and never put secrets anywhere.

**Exit gate** (each item needs an assertion that fails when violated):

- Read-only cannot write outside scratch, and its `POST` and raw-socket attempts are blocked.
- Full access acts only inside the project roots and the allowlist.
- A zero-root project writes only to scratch.
- `exec --json` emits a stable schema (snapshot test).
- The orientation block is at most 300 tokens (asserted).
