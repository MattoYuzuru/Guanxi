**Goal:** a small-context model works through an unlimited number of cycles without losing
the task.

**Scope (ROADMAP §R2):**

- the cycle state machine;
- thresholds computed from the reserves using the runtime's actual `W`;
- truncation detection;
- a run-scoped work ledger (ADR-0032 `run` mode);
- typed notes with deterministic selection and `notes.search`;
- a fresh-context narrative writer;
- `guanxi.handoff/v1`;
- sealing by fenced upload to the run home (R1's fencing; a stale attempt's seal is rejected);
- probes with defined failure transitions;
- an observed-progress counter;
- the normative caps;
- protected paths and clean-checkout gates.

Plan amendments from the relay are proposals only (D-158).

Further constraints:

- Every model call goes through K3 connections and the `egress.scrubber`, and every event goes
  to the K2 session log.
- Never put reasoning in plain logs, and never put secrets anywhere.
- Copy from Codex, OpenCode, OpenHands or Cline only under a licence that ADR-0016 allows. Record
  every copy in THIRD_PARTY_NOTICES in the same commit.

**Exit gate.** Each item needs an assertion that fails when the property is violated; prove
it by removing the guard.

- No request exceeds `H`. Use a fixture runtime that rejects oversize requests and a randomised
  property test over prompt, notes and tool output sizes.
- Ledger↔handoff hash consistency is 100% across every cycle boundary, including crash points.
- A corrupted handoff is caught by the probes.
- A failed narrative falls back to `degraded` without losing progress.
- A stale attempt's seal is rejected.
- A cycle that only adds notes does not count as progress.
