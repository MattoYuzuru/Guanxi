# Guanxi design system

**Status:** accepted direction (owner decisions D-127–D-140, revised by D-200–D-207); tokens and
components are implemented in stage DS1 and restyled in the UI-redesign lane · **Updated:** 2026-10-23

This folder is the brand book and style guide that every person and agent building Guanxi UI
follows. It is the source the catalog, the lint gates and the `guanxi-ui` skill are built from.

## How to use this folder

- **Building UI:** load the `guanxi-ui` skill
  ([`.agents/skills/guanxi-ui/SKILL.md`](../../.agents/skills/guanxi-ui/SKILL.md)), find an
  existing component in the catalog, and follow the decision ladder there.
- **Changing a token or adding a component:** follow
  [COMPONENTS_AND_CATALOG](COMPONENTS_AND_CATALOG.md); new components start as `draft`.
- **Reviewing UI:** use the checklist at the end of COMPONENTS_AND_CATALOG and the
  "broken when" lines in PRINCIPLES.

## What exists today

The 2026-10-23 redesign (D-200–D-207) replaced the verdigris look: a Porcelain + Cobalt working
palette (pending owner approval) generated by `packages/ui/tokens/palettes/`, white panes floating
on the chrome tone, icon status items with anchored popovers, one interface without the
Developer/Visual split, the D-207 composer, live data without Retry buttons, and an opt-in Max
graphics tier. Legacy web code keeps its frozen ratchets; the lane only shrank them.
