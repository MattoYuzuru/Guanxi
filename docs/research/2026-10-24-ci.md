# Parallel CI research and implementation evidence

**Status:** implemented; revision-specific hosted results live in the [PR checks](https://github.com/MattoYuzuru/Guanxi/pull/1/checks) and candidate artifact · **Date:** 2026-10-24

## Observed cost and behavior

The read-only audit found 1,620 retained Guanxi `agent-dev` receipts, including 681 exact
standard full-command hashes across 20–23 October. Full test commands (279 runs) accumulated
1,258.6 wall minutes; web browser 418.9, catalog browser 123.4 and builds 6.7. Summed times
are not CPU time, billing or unique defects. The latest sampled root test took 13.24 minutes:
UI gate self-tests 365.6 seconds, core 293.6. Caching a four-second production build would
not address the dominant cost. Repeated full suites and gate self-scans are the larger costs.

A bounded metadata-only scan of 154 Claude main/subagent transcripts deduplicated Bash tool
IDs and counted command calls, not successful operations: 375 calls containing `git commit`,
85 `git push`, 112 `git clone`, 109 `npm ci`, 318 shared-heavy invocations, 1,578 `tail` and
485 `sleep` calls. Dates in this sample are UTC, 19–23 October. Commands can contain several
operations, so counts are neither a precise push cadence nor success totals. No reasoning,
credentials, raw transcripts or private command contents were exported. The evidence supports
checkpoint-based commits, lead-owned publication, reuse of installations and process-owned
CI waiting; it does not support forcing additional commits/pushes per edit.

At implementation start local main was `4644f353`; remote main was `b3197d34`. The first CI
PR therefore also tests the owner's pre-existing locally integrated work. This migration does
not claim authorship of those feature changes. Existing lane snapshots are recorded locally;
one redesign fix clone had 15 dirty files, and is preserved without pulling or recloning.

| [Hosted runners](https://docs.github.com/en/actions/reference/runners/github-hosted-runners) | Public standard runners; Linux 26.04 for required util-linux support, isolated macOS signer envelope |

These are applied recommendations, not copied third-party implementation. No external agent
SDK or proprietary runtime is bundled. No new dependency or remote artifact cache service is
needed. Dependency downloads/layers avoid constant source-key misses; test/build output
reuse is deliberately deferred until there is a measured need and complete input identity.

## Implemented coverage and cache boundaries

The [protocol](../operations/ci.md) and [task registry](../../scripts/ci/tasks.mjs) define the
current envelope. Full history is required for signed UI approval lineage. Core shards retain
the ambient-key-file import guard and preserve literal Node test arguments. Linux jobs
prepare user namespaces, dependencies and the labelled native image; macOS runs the actual
Swift helper tests without claiming owner keychain/Touch ID validation. Catalog artifacts
use a mounted ignored path so failure diffs survive container cleanup.

Unknown workspace layout, added packages and unclassified test/build entrypoints fail the
inventory check. Future plugin/native/build additions require explicit platform, dependency,
cache and task classification; a hardcoded current matrix is never evidence that an unknown
future build is covered. Ordinary workspace typechecks remain discovered by npm. New
build outputs are not silently restored from incomplete cross-run cache keys.

## Independent review and fixes

A separate read-only reviewer inspected the implementation and platform assumptions. Six
actionable findings were fixed in a separate author commit `1d6d95d9`:

1. Ubuntu 24.04 lacks `setpriv --seccomp-filter`; use supported Ubuntu 26.04 and preflight it.
2. Partial reruns need the successful plan's same-run candidate artifact; use a stable name.
3. Root workspace-layout changes must fail discovery rather than omit future plugins.
4. CLI local guidance must typecheck CLI, not only server.
5. UI local guidance must typecheck UI; transpilation is not typechecking.
6. Catalog failure artifacts must survive host tmp paths and `docker --rm`.

## Validation: new / regression envelope

- **New:** eight focused CI tests cover inventory omissions/layout drift, draft/full task
  identity, actual disjoint Node shards and import guards, stale/missing/skipped/cancelled CI,
  partial reruns, affected module guidance and retained catalog artifact configuration.
- **New:** one documentation-discovery regression excludes CI/browser diagnostics while
  still rejecting broken source links; together with the 22 existing link tests the focused
  command passed **9 new / 22 existing = 31**, zero failures/skips.
- **Regression envelope:** the first draft hosted run
  [40073610479](https://github.com/MattoYuzuru/Guanxi/actions/runs/40073610479) passed plan and
  quality; Full gate was intentionally skipped because it was draft. This is not full evidence.
- actionlint and shellcheck validate the workflow/scripts. Revision-specific hosted results
  are recorded in the PR description, same-run candidate artifact and final response; tracked
  evidence is finalized before ready so writing a result does not trigger another full gate.

Fifteen existing lane checkouts received local, Git-excluded continuation adapters. Their
HEADs and dirty file lists were checked before/after and are unchanged; the 15 dirty files
in `redesign-f1` remain untouched. Three legacy full-gate launchers were backed up and
changed to scoped-guidance/final-CI adapters, so old invocations cannot silently restart
the serial full loop. The resume inventory is machine-local in `Guanxi-lanes/infra`.

## Remaining scope

The full hosted run and final documentation review are mandatory completion conditions. Existing
product-stage/live/hardware residuals remain; caching does not close them. Gate self-test
per-file caching and cross-run build/task-result caching are follow-ups requiring separate
correctness and timing evidence. No automatic baseline updates, assertion weakening, paid
model tests, self-hosted owner runner or removal of independent review is part of this slice.
