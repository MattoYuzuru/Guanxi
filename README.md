# Alamo UI

Локальный веб-интерфейс для Ollama: чат с историей, каталог моделей с проверкой железа,
агентный режим над директорией проекта, видимое окно контекста.

```bash
npx alamo-ui
```

Поднимает локальный сервер и открывает браузер. Ollama должен быть установлен и запущен.

## Устройство

| Пакет | Что делает |
|---|---|
| `packages/contract` | Единственный источник правды: zod-схемы всех роутов и SSE-событий |
| `packages/server` | Hono + `node:sqlite`, клиент Ollama, агентное ядро, инструменты |
| `packages/web` | React + Vite + Tailwind, карусель моделей, чат, панель контекста |
| `packages/cli` | `npx alamo-ui` — поднять сервер и открыть браузер |

Рантайм — Node 22.5+. Нативных зависимостей нет: SQLite берётся из встроенного `node:sqlite`,
поэтому `npx` работает на чистой машине без сборки.

## Разработка

```bash
npm install
npm run dev:server   # http://127.0.0.1:4310
npm run dev:web      # http://127.0.0.1:5173 (проксирует /api на сервер)
npm test
npm run typecheck
```

Чтобы команда `alamo-ui` была доступна напрямую из любого каталога на машине
разработчика, соберите CLI и создайте глобальную npm-ссылку:

```bash
npm run link:cli
alamo-ui
```

Ссылка ведёт на `packages/cli`, поэтому после изменений достаточно снова выполнить
`npm run build` — переустанавливать пакет не нужно.

## Правило контракта

`packages/contract` менять только согласованно. Сервер и веб импортируют типы оттуда и
нигде не описывают форму данных заново — расхождение между ними должно быть ошибкой
компиляции, а не багом в рантайме.

## Заметки по окружению

- Ollama по умолчанию выдаёт **4k контекста** при менее чем 24 ГБ VRAM. Приложение всегда
  передаёт `num_ctx` явно: 8k для чата, 32k для агентного режима.
- Не все модели отдают структурные `tool_calls` — многие возвращают JSON текстом в `content`.
  Парсер инструментов обязан понимать оба формата.
- За корпоративным прокси `bun install` падает на самоподписанном сертификате, а `npm install`
  работает. Если понадобится Bun или исходящие HTTPS-запросы из Node — задать
  `NODE_EXTRA_CA_CERTS` с корневым сертификатом компании.
